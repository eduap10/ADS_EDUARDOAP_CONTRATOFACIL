Editor de modelos

Escreva o texto e insira os dados da ficha por meio dos campos dinâmicos. Cada modelo pode ser reutilizado.

Como criar um modelo com campos automáticos?
  1. Selecione o tipo e dê um nome para identificar o modelo.
  2. Escreva normalmente o documento. Posicione o cursor onde deseja inserir um dado.
  3. Pesquise no painel Campos da ficha e clique no campo desejado, como Nome completo. No texto ficará {{colaborador.nome}}.
  4. Ative Exemplo preenchido para simular os valores, sem acessar dados reais.
  5. Salve o modelo. Na aba Contratos, selecione um colaborador cadastrado. A visualização e a exportação mostrarão os dados da ficha dele.

Se um atributo não tiver valor cadastrado, o documento indicará “Não informado”. Campos de exemplo são fictícios.

Componente selecionado

Componentes do documento

Adicione linhas, tabelas com células editáveis e espaços para assinatura. Passe o mouse para ver o uso.

Os componentes aparecem visualmente na área de criação. Clique para editar as propriedades acima, arraste para reposicionar entre parágrafos ou use a alça inferior para mudar a largura. Clique em “Editar células” para atualizar a tabela.

Inserir separador

O separador será inserido como objeto visual. Clique nele para escolher cor, espessura e orientação.

Inserir tabela editável

Preencha as células com textos ou tags (ex.: {{colaborador.nome}}). No editor, a tabela ficará visível para seleção, ajuste de tamanho e edição.

Inserir campo de assinatura

Um bloco de assinatura será inserido com a linha em cima e a identificação da pessoa abaixo. Os nomes são informados na emissão, sem alterar o modelo.

Campos da ficha

Encontre o atributo desejado e clique para inseri-lo no cursor. Passe o mouse para ver uma explicação.

Campos da ficha

Minhas tags

Nenhuma tag personalizada cadastrada. Use “Criar ou editar tags” para adicionar uma.

Dica: “Nome completo” insere a tag {{colaborador.nome}}, preenchida com o nome do colaborador escolhido na emissão.
