Editor de modelos

Escreva o texto e insira os dados da ficha por meio dos campos dinâmicos. Cada modelo pode ser reutilizado.

Como criar um modelo com campos automáticos?
  1. Selecione o tipo e dê um nome para identificar o modelo.
  2. Escreva normalmente o documento. Posicione o cursor onde deseja inserir um dado.
  3. Pesquise no painel Campos da ficha e clique no campo desejado, como Nome completo. No texto ficará {{colaborador.nome}}.
  4. Ative Exemplo preenchido para simular os valores, sem acessar dados reais.
  5. Salve o modelo. Na aba Contratos, selecione um colaborador cadastrado. A visualização e a exportação mostrarão os dados da ficha dele.

Se um atributo não tiver valor cadastrado, o documento indicará “Não informado”. Campos de exemplo são fictícios.
